# 온음

광고·구독·계정 없는 무료 음악 플레이어입니다. 휴대폰에 있는 음악 파일을 찾아 들려주고, 그 안에 복음을 향기처럼 담았습니다.

> 그 소리가 온 땅에 퍼졌고 그 말씀이 땅끝까지 이르렀도다 (롬 10:18, 개역한글)

## 시험판 받기

[시험판 페이지](../../releases/tag/test-build)에서 휴대폰으로 `onum-test.apk`를 내려받아 설치하세요. 처음 설치할 때 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.

## 지금 되는 것 (1.0 예루살렘, 만드는 중)

- 휴대폰 속 음악 자동 찾기 (30초 미만 소리, 통화·음성 녹음 제외)
- 초성 검색 ("ㄹㅅㄴ" → 리센느), 곡·가수·폴더별 보기
- 진짜 무작위 재생: 모든 곡을 한 번씩 다 튼 뒤 다시 섞기
- 이어 듣기, 화면이 꺼져도 계속 재생
- 오늘의 한 문장 (개역한글)

## 만들기

```bash
npm ci
npm run dev          # 컴퓨터 브라우저에서 보기
npm run build && npx cap sync android   # 안드로이드 프로젝트에 반영
```

`main`에 올리면 GitHub Actions가 APK를 만들어 시험판 페이지에 올립니다.

## 원칙

- 음악 파일과 듣는 기록은 기기 밖으로 나가지 않습니다. 서버도 계정도 없습니다.
- 인터넷에서 가사를 가져오지 않습니다.
- 성경 본문은 저작권이 끝난 개역한글(침례 표기), KJV, WEB만 씁니다.
